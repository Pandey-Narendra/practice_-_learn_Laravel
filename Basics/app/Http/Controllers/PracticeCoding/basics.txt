#### Core PHP / Basics

1. **Write a program to check if a number is prime in PHP.**  
   **Solution:**  
   ```php:disable-run
   function isPrime(int $num): bool {
       if ($num <= 1) return false;
       if ($num <= 3) return true;
       if ($num % 2 == 0 || $num % 3 == 0) return false;
       for ($i = 5; $i * $i <= $num; $i += 6) {
           if ($num % $i == 0 || $num % ($i + 2) == 0) return false;
       }
       return true;
   }
   // Example: var_dump(isPrime(11)); // true
   ```  
   **Explanation:** Check divisibility up to sqrt(n), skipping evens after 2/3. Time: O(sqrt(n)), Space: O(1). Insight: Efficient for large numbers; handle 1 as non-prime.

2. **Write a program to reverse a string without using built-in functions.**  
   **Solution:**  
   ```php
   function reverseString(string $str): string {
       $reversed = '';
       $len = 0;
       while (isset($str[$len])) $len++;
       for ($i = $len - 1; $i >= 0; $i--) $reversed .= $str[$i];
       return $reversed;
   }
   // Example: echo reverseString("hello"); // "olleh"
   ```  
   **Explanation:** Manual length calculation, loop from end. Time: O(n), Space: O(n). Insight: PHP strings immutable; for Unicode, use mb_ functions.

3. **How do you swap two numbers without using a third variable?**  
   **Solution:**  
   ```php
   function swap(&$a, &$b) {
       $a = $a + $b;
       $b = $a - $b;
       $a = $a - $b;
   }
   // Example: $x=5; $y=10; swap($x,$y); echo "$x $y"; // 10 5
   ```  
   **Explanation:** Arithmetic addition/subtraction. Time: O(1), Space: O(1). Insight: Risk of overflow for large ints; use list() for arrays or XOR for bits.

4. **Write a program to find the factorial of a number using recursion.**  
   **Solution:**  
   ```php
   function factorial(int $n): int {
       return ($n <= 1) ? 1 : $n * factorial($n - 1);
   }
   // Example: echo factorial(5); // 120
   ```  
   **Explanation:** Recursive call until base case. Time: O(n), Space: O(n). Insight: Iterative for large n to avoid stack overflow; use GMP for bigints.

5. **Write a program to generate Fibonacci series up to n terms.**  
   **Solution:**  
   ```php
   function fibonacci(int $n): array {
       $fib = [0, 1];
       for ($i = 2; $i < $n; $i++) $fib[$i] = $fib[$i-1] + $fib[$i-2];
       return array_slice($fib, 0, $n);
   }
   // Example: print_r(fibonacci(10));
   ```  
   **Explanation:** Iterative build from 0,1. Time: O(n), Space: O(n). Insight: Space optimize to O(1) by tracking only last two.

6. **Write a program to check if a string is a palindrome.**  
   **Solution:**  
   ```php
   function isPalindrome(string $str): bool {
       $str = strtolower(preg_replace('/[^a-z0-9]/', '', $str));
       $len = strlen($str);
       for ($i = 0; $i < $len / 2; $i++) {
           if ($str[$i] !== $str[$len - $i - 1]) return false;
       }
       return true;
   }
   // Example: var_dump(isPalindrome("radar")); // true
   ```  
   **Explanation:** Clean string, compare halves. Time: O(n), Space: O(1). Insight: Regex optional; manual loop for perf.

7. **How to count the number of vowels and consonants in a string?**  
   **Solution:**  
   ```php
   function countVowelsConsonants(string $str): array {
       $vowels = $consonants = 0;
       $str = strtolower($str);
       for ($i = 0; isset($str[$i]); $i++) {
           if (preg_match('/[aeiou]/', $str[$i])) $vowels++;
           elseif (preg_match('/[a-z]/', $str[$i])) $consonants++;
       }
       return ['vowels' => $vowels, 'consonants' => $consonants];
   }
   // Example: print_r(countVowelsConsonants("hello"));
   ```  
   **Explanation:** Loop and check char type. Time: O(n), Space: O(1). Insight: Use strspn for faster counting.

#### Sorting / Searching

41. **Implement Bubble Sort in PHP.**  
    **Solution:**  
    ```php
    function bubbleSort(array $arr): array {
        $n = count($arr);
        for ($i = 0; $i < $n - 1; $i++) {
            $swapped = false;
            for ($j = 0; $j < $n - $i - 1; $j++) {
                if ($arr[$j] > $arr[$j+1]) {
                    [$arr[$j], $arr[$j+1]] = [$arr[$j+1], $arr[$j]];
                    $swapped = true;
                }
            }
            if (!$swapped) break;
        }
        return $arr;
    }
    // Example: print_r(bubbleSort([5,3,1]));
    ```  
    **Explanation:** Adjacent swaps. Time: O(n^2). Insight: Optimized with flag.

42. **Implement Insertion Sort in PHP.**  
    **Solution:**  
    ```php
    function insertionSort(array $arr): array {
        $n = count($arr);
        for ($i = 1; $i < $n; $i++) {
            $key = $arr[$i];
            $j = $i - 1;
            while ($j >= 0 && $arr[$j] > $key) {
                $arr[$j + 1] = $arr[$j];
                $j--;
            }
            $arr[$j + 1] = $key;
        }
        return $arr;
    }
    ```  
    **Explanation:** Insert into sorted part. Time: O(n^2). Insight: Good for nearly sorted.

    ```php
    function selectionSort(array $arr): array {
        $n = count($arr);
        for ($i = 0; $i < $n - 1; $i++) {
            $minIdx = $i;
            for ($j = $i + 1; $j < $n; $j++) {
                if ($arr[$j] < $arr[$minIdx]) $minIdx = $j;
            }
            [$arr[$i], $arr[$minIdx]] = [$arr[$minIdx], $arr[$i]];
        }
        return $arr;
    }
    ```  
    **Explanation:** Select min and swap. Time: O(n^2). Insight: Fewer swaps than bubble.

44. **Implement Quick Sort in PHP.**  
    **Solution:**  
    ```php
    function quickSort(array $arr): array {
        if (count($arr) <= 1) return $arr;
        $pivot = $arr[0];
        $left = $right = [];
        for ($i = 1; $i < count($arr); $i++) {
            $arr[$i] < $pivot ? $left[] = $arr[$i] : $right[] = $arr[$i];
        }
        return array_merge(quickSort($left), [$pivot], quickSort($right));
    }
    ```  
    **Explanation:** Partition and recurse. Time: O(n log n) avg. Insight: Random pivot for balance.

45. **Implement Merge Sort in PHP.**  
    **Solution:**  
    ```php
    function mergeSort(array $arr): array {
        if (count($arr) <= 1) return $arr;
        $mid = (int)(count($arr) / 2);
        $left = mergeSort(array_slice($arr, 0, $mid));
        $right = mergeSort(array_slice($arr, $mid));
        return merge($left, $right);
    }
    function merge(array $left, array $right): array {
        $merged = [];
        $i = $j = 0;
        while ($i < count($left) && $j < count($right)) {
            $merged[] = $left[$i] <= $right[$j] ? $left[$i++] : $right[$j++];
        }
        return array_merge($merged, array_slice($left, $i), array_slice($right, $j));
    }
    ```  
    **Explanation:** Divide, conquer, merge. Time: O(n log n). Insight: Stable sort.

    ```php
    function binarySearch(array $arr, $target): int {
        $left = 0;
        $right = count($arr) - 1;
        while ($left <= $right) {
            $mid = (int)(($left + $right) / 2);
            if ($arr[$mid] === $target) return $mid;
            elseif ($arr[$mid] < $target) $left = $mid + 1;

        }
        return -1;
    }
    ```

51. **Implement Heap Sort in PHP.**  
    **Solution:**  
    ```php
    function heapSort(array &$arr) {
        $n = count($arr);
        for ($i = (int)($n / 2) - 1; $i >= 0; $i--) heapify($arr, $n, $i);
        for ($i = $n - 1; $i > 0; $i--) {
            [$arr[0], $arr[$i]] = [$arr[$i], $arr[0]];
            heapify($arr, $i, 0);
        }
    }
    function heapify(array &$arr, int $n, int $i) {
        $largest = $i;
        $left = 2 * $i + 1;
        $right = 2 * $i + 2;
        if ($left < $n && $arr[$left] > $arr[$largest]) $largest = $left;
        if ($right < $n && $arr[$right] > $arr[$largest]) $largest = $right;
        if ($largest != $i) {
            [$arr[$i], $arr[$largest]] = [$arr[$largest], $arr[$i]];
            heapify($arr, $n, $largest);
        }
    }
    ```  
    **Explanation:** Build max heap, extract. Time: O(n log n). Insight: In-place.
