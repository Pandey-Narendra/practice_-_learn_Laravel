1) php artisan make:factory ModelNameFactory --model=ModelName
        These are classes that generate fake data for your Eloquent models. 
        They're essential for testing, seeding databases, and prototyping. 
        In Laravel 12, factories use PHP attributes for better readability and support faker providers out-of-the-box.

2) use Illuminate\Database\Eloquent\Factories\Factory;

3) Define the properties
    
        return [
            'user_id' => User::factory(), // creates a new user automatically
            'name' => $this->faker->word(),
            'title' => $this->faker->sentence(), 
            'slug' => Str::slug($title),
            'body' => $this->faker->paragraph(5),
            'category' => $this->faker->randomElement(['Electronics', 'Clothing', 'Books', 'Toys']),
            'price' => $this->faker->randomFloat(2, 100, 10000),
            'stock' => $this->faker->numberBetween(0, 500),
            'created_at' => $this->faker->dateTimeBetween('-1 year', 'now'),
        ];

5) php artisan make:seeder EcommerceSeeder

        These are classes that populate your database with initial data using factories or direct inserts. 
        They're run via Artisan commands and are great for setting up default data (e.g., admin users, categories).

        | Method            | Example                                                        | What It Does                                |
        | ----------------- | -------------------------------------------------------------- | ------------------------------------------- |
        | `factory()`       | `User::factory()`                                              | Calls the factory associated with the model |
        | `count(n)`        | `->count(10)`                                                  | Creates `n` instances                       |
        | `create()`        | `->create()`                                                   | Persists data into the database             |
        | `make()`          | `->make()`                                                     | Generates data but doesn’t save to DB       |
        | `for()`           | `->for(User::factory())`                                       | Defines a `belongsTo` relationship          |
        | `has()`           | `->has(Comment::factory()->count(3))`                          | Defines a `hasMany` relationship            |
        | `sequence()`      | `->sequence(['status' => 'active'], ['status' => 'inactive'])` | Generates sequential variations             |
        | `state()`         | `->state(fn() => ['role' => 'admin'])`                         | Customizes specific attributes dynamically  |
        | `afterCreating()` | Hook after creation                                            | Runs extra logic after records are created  |
        | `afterMaking()`   | Hook before saving                                             | Runs logic before model is persisted        |


        // Basics\database\seeders\EcommerceSeeder.php
        public function run(): void
        {
                // Create 10 users
                $users = User::factory(10)->create();

                // Create 10 products
                $products = Product::factory(20)->create();

                // Create Order with Order Items for the random Users
                $orders = Order::factory(20)
                        ->for($users->random())
                        ->has(OrderItem::factory()->count(3))
                        ->create()
                ;

                // Create a post with Comments and Like for random users
                $post = Post::factory(10)
                        ->for($users->random())
                        ->has(Comment::factory()->count(3))
                        ->has(Like::factory()->count(5))
                        ->create()
                ;

                // Output success message
                $this->command->info('Fake data for Products, Orders, Posts, Comments, and Likes created successfully!');
        }

6) inside main seeder (Basics\database\seeders\DatabaseSeeder.php)
        
        $this->call(EcommerceSeeder::class);

7) php artisan db:seed or php artisan db:seed --class=EcommerceSeeder

8) php artisan migrate:fresh --seed
        This command drops all tables, recreates them, and runs all seeders — perfect during development
